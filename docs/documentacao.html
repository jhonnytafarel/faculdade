2. Resumo Executivo

A Fábrica de Software Jhonny Tafarel teve a honra de desenvolver o Sistema de Cadastro de Veículos para atender à demanda do cliente. O projeto foi construído utilizando tecnologias consolidadas no mercado de desenvolvimento web, com foco em simplicidade, funcionalidade e facilidade de manutenção.

O sistema permite o cadastro completo de veículos com informações como placa, marca, modelo, cor, ano de fabricação, ano do modelo, combustível, chassi, renavam, quilometragem, data de cadastro e observações. Além disso, oferece uma tela de listagem dinâmica com DataTables, permitindo busca, ordenação, paginação e ações de editar e deletar registros.

A comunicação entre front-end e back-end é realizada via APIs em JSON, garantindo uma arquitetura moderna e desacoplada. O sistema foi desenvolvido para rodar em ambiente local (XAMPP), mas pode ser facilmente migrado para um servidor de produção.

6. Guia de Instalação e Configuração

Passo 1: Instalar o XAMPP

Baixe e instale o XAMPP a partir do site oficial: https://www.apachefriends.org. Durante a instalação, certifique-se de selecionar Apache, MySQL e PHP.

Passo 2: Configurar a pasta do projeto

Copie todos os arquivos do sistema para a pasta do servidor web:

D:\xampp\htdocs\faculdade\

Passo 3: Criar o banco de dados

Acesse o phpMyAdmin pelo navegador:

http://localhost/phpmyadmin

Importe o arquivo banco_de_dados.sql ou execute os comandos SQL diretamente:

CREATE DATABASE IF NOT EXISTS faculdade; USE faculdade; CREATE TABLE IF NOT EXISTS veiculos ( id INT PRIMARY KEY AUTO_INCREMENT, placa VARCHAR(10) NOT NULL, marca VARCHAR(50) NOT NULL, modelo VARCHAR(50) NOT NULL, cor VARCHAR(30) NOT NULL, ano_fabricacao INT NOT NULL, ano_modelo INT NOT NULL, combustivel VARCHAR(20) NOT NULL, chassi VARCHAR(50) NOT NULL, renavam VARCHAR(50) NOT NULL, quilometragem INT NOT NULL, data_cadastro DATE NOT NULL, observacoes TEXT NOT NULL );

Passo 4: Configurar a conexão com o banco

Edite o arquivo conexao.php caso as credenciais do MySQL sejam diferentes:

$host = "localhost"; $usuario = "root"; // usuário do MySQL $senha = ""; // senha do MySQL (vazio por padrão no XAMPP) $banco = "faculdade"; // nome do banco de dados

Passo 5: Iniciar os serviços

Abra o Painel de Controle do XAMPP e inicie o Apache e o MySQL.

Passo 6: Acessar o sistema

Abra o navegador e acesse:

http://localhost/faculdade/

7. Guia de Uso do Sistema

7.1 Tela Inicial (index.php)

A página inicial apresenta uma breve descrição do projeto, as funcionalidades disponíveis e um menu de navegação para acessar as demais telas.

7.2 Cadastrar Veículo (cadastro.php)

  1. Acesse o menu Cadastrar
  2. Preencha todos os campos do formulário (todos são obrigatórios)
  3. Ou clique no botão "🎲 Preencher dados aleatórios" para testar o sistema
  4. Clique em Salvar Veículo
  5. Um alerta de sucesso com efeito de confete confirmará o cadastro

7.3 Listar Veículos (listagem.php)

  1. Acesse o menu Listagem
  2. A tabela carregará automaticamente todos os veículos cadastrados
  3. Use a caixa de busca para filtrar por qualquer campo
  4. Use os controles de paginação para navegar entre páginas
  5. Clique nos cabeçalhos para ordenar por coluna

7.4 Editar Veículo

  1. Na tela de listagem, clique no botão Editar (amarelo) na linha do veículo
  2. Altere os campos desejados no formulário
  3. Clique em Atualizar Veículo
  4. Um alerta de sucesso com confete confirmará a atualização

7.5 Deletar Veículo

  1. Na tela de listagem, clique no botão Deletar (vermelho) na linha do veículo
  2. Confirme a exclusão no alerta que aparecerá
  3. O veículo será removido e a tabela será atualizada automaticamente

9. Manutenção e Suporte

9.1 Backup do Banco de Dados

Recomendamos realizar backups periódicos do banco de dados. No phpMyAdmin, selecione o banco faculdade, vá até a aba Exportar e escolha o formato SQL.

9.2 Log de Erros

O PHP pode estar configurado para exibir erros. Em ambiente de produção, recomenda-se desabilitar a exibição de erros no arquivo php.ini:

display_errors = Off log_errors = On error_log = "D:/xampp/php/logs/php_error_log"
